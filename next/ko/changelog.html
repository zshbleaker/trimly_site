1.8.12026년 10월

위젯, 시간대, 다중 선택

새로운 기능

  • 내보내는 파일에 사용할 시간대를 조정
  • 데스크톱 위젯 추가
  • 단축어 지원 개선
  • 여러 파일을 선택하고 파일 목록 정렬

버그 수정

  • 사진에서 가져온 동영상이 재시작 후 보관함에서 사라질 수 있던 문제 수정
  • 네트워크 위치에서 PCM 오디오를 열 때 발생할 수 있던 충돌 수정
  • 인터페이스를 다듬고 전반적인 안정성 개선

1.82026년 10월

카메라 하이라이트 표시와 화면 텍스트

새로운 기능

  • GoPro HiLight와 DJI 하이라이트 표시가 클립 찾기와 타임라인에 나타남
  • 클립 찾기에서 화면에 나타난 텍스트를 검색할 수 있음
  • 스크립트가 내보낸 동영상에 자막 트랙으로 포함됨
  • 회전과 내보내기 중에도 공간 오디오를 유지하며, 내보내기에서 공간 오디오가 평면화될 때 경고 표시
  • 촬영 시간과 장소가 사진 앱에서 한 변경을 따라감
  • 필름스트립에 마우스를 올려 동영상을 훑어볼 수 있음
  • 파일 정보에서 파일의 출처와 내보낸 내역 표시

1.72026년 9월

Spotlight

새로운 기능

  • Spotlight에서 Trimly 파일을 찾을 수 있음
  • Trimly 액션이 Siri 제안에 표시됨

1.62026년 7~9월

Apple TV, 네트워크 공유, 클립 찾기

새로운 기능

  • Apple TV의 Trimly
  • SMB와 WebDAV 공유의 동영상을 열고 편집
  • 새로운 홈 화면 그리드: 오디오는 카세트, 무손실 파일은 바이닐로 표시
  • 편집 프로그램용 FCPXML과 EDL 내보내기
  • 클립 찾기에서 하이라이트, 음악 분석, 피사체, 스크립트, 소리를 한곳에 모음
  • 스마트 썸네일과 자동 클립 이름
  • 선택한 클립만 내보내기
  • 자르기, 기울기 보정, 원근 보정
  • 편집 지점이 음성, 무음, 비트에 맞춰 붙음
  • 메시지 스티커

1.52026년 7월

기기 내 받아쓰기

새로운 기능

  • 길게 눌러 재생 속도 올리기, 스와이프로 볼륨 조절
